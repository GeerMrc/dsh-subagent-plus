# dsh-subagent-plus（子智能体路由）

> 按策略为所有子智能体指派 LLM 路由：钉定单一路由，或在候选清单间轮询/随机/优先级分配——支持角色关键词映射、按能力自动派生、健康降级与兜底。

## 它做什么

- **候选清单**（≤5 条）：你的备选模型路由，按所选策略分配给每个子智能体
- **Team 角色映射**：名字含关键词的队友走指定路由；默认 12 行跨领域模板按模型能力自动派生（质量把关/执行构建/快速验证三族各就其位），候选增删即时全表重评
- **能力评估**：导出调研任务交任意强模型评分，回贴导入即参与排序（可一键清除回退内置快照）
- **健康降级**：路由失败自动冷却，下一步边界换到健康候选；三层接管链（行模型 → 其余候选 → 兜底）
- **子窗口徽章**：每个子智能体输入框旁显示当前路由

## 关闭插件

**插件页的开关是本插件唯一的关闭入口**——关闭后所有子智能体恢复宿主默认路由。

## 兼容性

DSH ≥ 0.2.2（`agent.model.select` 通道）；更早宿主上路由不生效（日志有一次性提示）。
