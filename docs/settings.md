# 设置页使用手册 / Settings page manual（v0.2.0，插件 dsh-subagent-plus）

设置 → **子Agent增强**。所有保存写入与手改 `cordis.patch.yml` 相同的 profile patch 层，且**热生效**（对新决策立即生效，无需重启；进行中的子 Agent 保持原路由，健康表/轮询游标/粘住决策全部保留）。

## 页面结构

| 区块 | 控件 | 说明 |
|---|---|---|
| 页头 | 标题 + ⓘ 悬停说明 + **右侧接管开关**（默认开，绿） | 开关即"接管中/已停用"（悬停可见：本插件在官方设置之上叠加指派，关闭即完整恢复官方）；随整页草稿一起保存 |
| 单张设置卡 | 全部配置收在同一张卡内，每行紧凑单行（左：标题+ⓘ 悬停；右：控件） | ① 卡头行自适应（pinned=「钉定路由」下拉右置 + **推理强度下拉**；非 pinned=「候选模型清单」ⓘ）；② 清单行（每行：序号+模型名+**该模型的推理强度下拉**；**悬停/单击模型名**弹出紧凑横向操作条：首行仅 下移+删除、末行仅 上移+删除、中间行 上移+下移+删除——边界行不出现不可操作项；无档位模型不显示下拉）→ 添加模型行（左标签+右下拉，**最多 5 条**、顺序即优先级）→ 分配策略行（策略下拉右置）；③ 兜底模型行（短标签紧凑下拉 + **推理强度下拉**，**悬停显示完整路由名**；候选全部不可用或清单为空时的最后路由，清单空+兜底=「单固定模型」入口）；④ **高级**折叠区（默认收起，**右侧箭头**展开，组内行间无分割线）：respectExplicit / showNotice / pinForkChildren / failOpen / autoRoute / cooldownMs（0=关闭健康跟踪），每项单行、说明仅在 ⓘ 悬停中 |

保存按钮在"有修改且配置合法"时可用；非法组合（结构性：超 5 条/半填/重复；跨字段：优先级空清单、兜底半填/重复）会被**禁止保存**并显示原因——这同时防住了"保存一个重启后会让插件加载失败的组合"。

## 行为要点

- **保存即热生效**：改策略/清单只影响下一个决策点——已粘住路由的运行中子 Agent 不动，直到其路由进入冷却。
- **兜底触发条件**：候选全部冷却/未注册或清单为空。故障切换时**优先下一个健康候选**，兜底垫底；兜底自身故障同样进冷却，全部不可用时保持原路由（failOpen 语义）。
- **设置页与手改 yml 等价同层**：任何时刻都可回到 yml 手改或删除条目。
- **远程 web 会话限制**：非本机（非 loopback）访问时保存仅当前会话生效（官方 configForms 的 memory 持久化语义）；桌面端与本机访问=持久落盘。
- **修订冲突**：配置在其他位置（如另一窗口）被改过时，保存会提示"已被修改，已重新加载"——重试即可。

## 验证方式

- 子 Agent 转录首行提示：`[model pinned/assigned/fallback: …]`；子窗口琥珀色徽章显示实际路由。
- Host 日志：`assigned (round-robin) child agent onto …`、`route "sz/…" failed (RATE_LIMIT); cooling down …`、`… continues with "hh/…"`。
- 端到端回归流程见 `docs/e2e-manual.md`（三 Flow：改策略/配兜底+死路由降级/禁用回官方）。


## 推理强度下拉（v0.2.0）

- 选项来自**所选模型自身**的档位配置（目录 reasoning）：如 qwen 系 `Off/Low/Medium/Xhigh`、zai 系 `Low/High/Max`、无档位模型（如部分 Kimi）不显示下拉（钉定/兜底处显示禁用态）。
- 首项恒为「**默认**」（短标签，收窄占位）——不写该键，由 DSH 物化模型默认档位；**悬停选框**显示详情「跟随模型默认档位（当前：<档名>）」。
- 已存但当前模型不支持的档位 id 会**原样可见**（不会被静默改写），保存后由运行时校验兜底。
- 清空路由 → 档位清空；切换路由 → 已选档位在新模型仍支持时保留，否则回落「跟随默认」。
