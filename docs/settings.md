# 设置页使用手册 / Settings page manual（v0.0.4，插件 dsh-subagent-plus）

设置 → **子Agent增强**。所有保存写入与手改 `cordis.patch.yml` 相同的 profile patch 层，且**热生效**（对新决策立即生效，无需重启；进行中的子 Agent 保持原路由，健康表/轮询游标/粘住决策全部保留）。

## 页面结构（v0.0.4：运行限制与候选清单同卡，候选清单=官方模型选择完整替代）

| 区块 | 控件 | 说明 |
|---|---|---|
| 页头 | 标题 + 描述行 | 描述说明接管事实与唯一关闭入口（「插件」页停用本插件）。页内无任何开关（ADR 0005 纯二进制） |
| **合并设置卡**（单一边框） | 卡内自上而下：**运行限制**子区（标题+ⓘ+已保存徽标 + 深度/并行两个数字输入，64px 居中定宽）→ 留白 → **候选模型清单**（卡头行 + 清单行 + 添加行 + 策略行）→ **兜底模型行**（短标签下拉 + 推理强度下拉，悬停完整路由；候选全部不可用或清单为空时的最后路由，清单空+兜底=「单固定模型」入口） | 运行限制同键写入官方 `subagent` 命名空间（强制仍由官方运行时执行，立即生效；非法输入**阻塞整次保存**；接管声明在 ⓘ 悬停中——官方页已接管、同一事实源、插件页停用即恢复）。候选清单即官方「模型选择」的完整替代（ADR 0003）：策略/逐模型推理强度/兜底/健康冷却；官方授权清单无编辑面、运行时零引用（ADR 0005）——候选清单是唯一路由来源；未配置路由（钉定空+清单空+无兜底）时页面明示"不指派，子智能体继承主会话模型"。pinned 策略下卡头为「钉定路由」下拉+推理强度；非 pinned 为清单行（序号+模型名+悬停操作条+推理强度下拉，≤5 条）+ 添加行 + 策略行 |
| 本插件命名空间失活分支 | 合并卡内状态行 | 本插件自身 ns 不可用/不可识别时仅策略半区转状态行，**运行限制子区照常编辑保存**（T7：接管期间不死锁）；官方 ns 失活仅运行限制子区转不可用行 |
| **高级**折叠区 | 行式开关/输入 | respectExplicit（pinned 下置灰，仅轮询/随机/优先级生效——显式指派**也优先于角色关键词映射**，ADR 0013）/ showNotice / pinForkChildren / failOpen / cooldownMs（88px 居中；上限 86400000；钉定且未配兜底时冷却完全不参与并显示"当前配置下不生效"提示行；0=关闭在 ⓘ 内） |
| 页脚 | **全页唯一保存按钮** + 状态反馈 | 一次点击按固定顺序提交两个命名空间（运行限制 → 本插件配置），各自修订栅栏；失败在页脚点名分区 |

**统一保存门控**（v0.0.3）：按钮在"任一命名空间有修改且无阻塞项"时可用。任一**已服务**命名空间输入非法（运行限制解析失败 / 插件结构性或跨字段非法）阻塞**整次**保存（官方单表单语义）；**失活**的命名空间仅显示不可用行并被本次保存**排除**；首个冲突或传输失败**中止后续**命名空间并点名分区，已提交的分区保持已保存。

## 行为要点

- **保存即热生效**：改策略/清单只影响下一个决策点——已粘住路由的运行中子 Agent 不动，直到其路由进入冷却。
- **官方设置页接管**（v0.0.3 起）：插件启用期间官方「子智能体」设置页被隐藏（bundle patch disable，编辑面而已）；运行限制经本页同键读写官方命名空间，单一事实源。禁用/卸载插件后官方页面回归（生产宿主 hmr；源码启动宿主需重启），配置值保留；已存在子 Agent 从下一次请求起回官方解析。用户层 patch 写 `{id: ui-settings-subagent, disabled: false}` 可随时强制恢复官方页面（逃生门）。
- **候选清单=唯一路由来源**（ADR 0005）：官方授权清单无编辑面且运行时零引用；未配置路由=不指派（继承主会话模型）。需调整官方清单（如 `respectExplicit=true` 的白名单）时，到「插件」页停用本插件后官方页回归编辑，或手改 profile patch 的 `subagent-model-selection-settings` 行。
- **兜底触发条件**：候选全部冷却/未注册或清单为空；钉定路由故障（冷却）或未注册被跳过时同样由兜底接手。故障切换时**优先下一个健康候选**，兜底垫底；兜底自身故障同样进冷却，全部不可用时：已粘住路由的子 Agent 保持原路由继续尝试，新子 Agent 不指派（继承主会话模型）。
- **设置页与手改 yml 等价同层**：任何时刻都可回到 yml 手改或删除条目。
- **远程 web 会话限制**：非本机（非 loopback）访问时设置命名空间整区不可用——读写都不可用（官方 configForms 的 memory 持久化语义，describe mirror 不加载），配置区转不可用行；页内开关已随 ADR 0005 删除，远程会话请到本机「插件」页停用本插件（或改 profile）；桌面端与本机访问=持久落盘。
- **修订冲突**：配置在其他位置（如另一窗口）被改过时，保存会提示"已被修改，已重新加载"（分区点名）——重试即可。

## 验证方式

- 子 Agent 转录首行提示（**中英双语单行**）：`[模型钉定 model pinned: 本子智能体所有请求运行 sz/…｜every request runs sz/… — dsh-subagent-plus]`、`[模型指派 model assigned: …（策略：轮询｜strategy: round-robin）— dsh-subagent-plus]`（兜底/切换/failOpen 跳过同格式）；子窗口琥珀色徽章显示实际路由。
- Host 日志：`assigned (round-robin) child agent onto …`、`route "sz/…" failed (RATE_LIMIT); cooling down …`、`… continues with "hh/…"`。
- 端到端回归流程见 `docs/e2e-manual.md`（Flow A/B/C：改策略/配兜底+死路由降级/空配置不指派对照；**Flow E：接管面**——官方页隐藏/统一保存写入官方命名空间/页头无开关断言/重启回归）。

## 交互反馈分界（v0.0.4，ADR 0016 UX 注记）

事件性结果（一次性动作确认）＝**瞬态**：页脚"已保存"约 3 秒自动消失（失败/冲突/被阻**常驻**至下次保存——需你行动）；导出成功＝按钮自身短暂变"已复制 ✓"（边框脉冲，系统"减少动态"下仅文字替换）；导入成功＝按钮变"已导入 N 行"；恢复默认＝按钮变"已恢复默认"＋Team 待保存徽标即现。

状态性条件（持续成立、回头要能再读）＝**常驻**：待保存徽标（保存后消失）、恢复默认禁用态、全部输入校验红框/红字、失败与冲突提示、目录加载失败、悬空路由行、overrides 列表与命中徽标。导入被拒的逐条原因显示在导入面板**内部**（红字，下次开面板/取消/应用时清退）。

## 推理强度下拉

- 选项来自**所选模型自身**的档位配置（目录 reasoning）：如 qwen 系 `Off/Low/Medium/Xhigh`、zai 系 `Low/High/Max`、无档位模型（如部分 Kimi）不显示下拉（钉定/兜底处显示禁用态）。
- 首项恒为「**默认**」（短标签，收窄占位）——不写该键，由 DSH 物化模型默认档位；**悬停选框**显示详情「跟随模型默认档位（当前：<档名>）」。
- 已存但当前模型不支持的档位 id 会**原样可见**（不会被静默改写），保存后由运行时校验兜底。
- 清空路由 → 档位清空；切换路由 → 已选档位在新模型仍支持时保留，否则回落「跟随默认」。


## Team（角色关键词 → 路由）（v0.0.4，ADR 0006＋0007＋0008＋0010＋0012＋0014＋0016）

- 位置：合并卡内、策略选择行与兜底行之间；两种策略下均常显。
- **匹配语义**：队友名**包含**行关键词即命中（子串匹配，最长关键词优先）。关键词越短命中越广（最短 2 字符，最长 64，lower-kebab-case，不可为 `lead`）。
- **路由选定时机**：子智能体创建时经官方 `agent.model.select()` API 选定（在 step preparation 之前，0.2.2+ 宿主的正规通道）。冷却中的路由在**下一步边界**自动换到下一健康候选或兜底。
- **路由目标只能取自候选清单**（≤5 条；多行可共用）。钉定策略下映射区只读（含档位下拉）。候选行的 上移/下移/删除 悬停**行首序号**出现（与 Team 行同锚位约定）；Team 标题 ⓘ 悬停动态包含模型态提示（全缺 coding 主锚／噪声带分差与调序说明）。
- **maxTokens**：继承预算跟随新路由持续生效（ADR 0010 裁定）。
- 校验（structural）：重名／半填／非法关键词（<2 字符）／悬空引用／超 32 行。
- fork 队友默认不被改写；空表＝休眠。
- `respectExplicit=true` 时，主智能体委派**显式指定**的模型（创建路由 ≠ 父会话当前路由）优先于关键词映射与策略链；恰等于父路由的指派无法识别（继承，ADR 0013 d4）。

### 默认映射（ADR 0014→0016，安装即生效）

- **无需任何操作**：`nameMapDefaults` 开启时（新装/空表缺省即开；已有自定义行自动落关），Team 区直接显示由候选清单按**三维度基准评分**派生的 12 行跨领域映射。三族独立排序：质量把关族（review/audit/verif/plan）coding 权重主导取最强；执行构建族（research/dev/build/execute/write/design）webdev 倾斜取居中；快速验证族（test/qa）取 S 权重下最弱者（成本/延迟间接代理）。**同模型可现于多族，档位按各族意图独立物化**。
- **评分来源（三层）**：①内置基准快照（LMArena text/coding＋webdev＋agent 子集 CC-BY-4.0、Aider polyglot Apache-2.0 等；各维度 rank-fraction 百分位；快照日期悬停 ⓘ 可见；随插件版本月更）→ ②**用户导入评估优先**（0-100 分布位置分线性 /100；维度级覆盖）→ 缺段按 0.5 中位填充（不重归一——缺席证据不得反超已证实能力）；缺 coding 主锚＝estimated（不参与 S/F 胜出）。
- **匹配管线（F 轮加固）**：官方别名表（`deepseek-flash`→V4.1-Flash 族、`k3`→Kimi-K3 族等）→直查→逐层剥量化/日期/上下文（256k/128k）后缀→变体扇出（最长词干优先；裸厂牌永不扇出）；版本分隔符归一（`claude-opus-4-8`≡`4.8`、`claude-3.5-sonnet`≡`3-5`）；OpenRouter slug 别名（构建期交叉，仅补运行期折叠不了的形态）；provider 部署名（strata/sz 等）绝不参与；完全未收录＝**三槽最后备选**（绝不因 argmin 被推去接测试族）。
- **未收录可见性（F2）**：候选行"未收录"徽章（悬停三态说明＋导入评估立即补全提示）；defaultsHint 下汇总行"N 个候选未收录，暂不参与槽位分配"；运行时对混合列表（有已收录候选时被排除的未收录候选）记录一次性告警日志——排除不再沉默；全未收录清单不告警（列表序回退是契约行为）。
- **槽位多样性（F3）**：B（执行构建族）中位与 S（质量把关族）撞同一模型时向两侧外步进取最近不同模型（等距取强侧）；F 在去重后的合格池上重选——同一模型多路由挂载不再扭曲取舍（provider 限定行刻意分化的双路由均保留）。多样性承诺仅在各槽自己的池含 ≥3 个不同模型时成立；两候选行为不变。
- **占用链与噪声带（G 轮）**：S→B→F 依次感知全部前序占用者——F 撞 B/S 时让位给未占用候选中最弱者（≥3 不同模型门内）；S 槽 0.02 分差噪声带内按**清单顺序**裁定（你的排位即优先级；带外纯分数）。
- **同模型多入口分摊（G4）**：同一模型经多供应商接入＝部署副本——其族内行交替分摊等权负载（如双入口 6+6/12），每行按各自入口档位表物化；路由限定评分刻意分化的主备不参与分摊。
- **三层故障接管（G3）**：行模型故障/冷却 → 其余健康候选接管（同模型健康入口优先）→ 兜底模型（终末级，可在清单外）；接管在转录中通知；设置页显示"N 个候选不占模板行"提示。
- **双消费先序（H3）**：同一候选清单服务两个消费方——命中关键词的子智能体走 Team 行（含物化档位），未命中的走策略链（轮询/随机/优先级）；显式指定（respectExplicit 开启时）压过两者；清单顺序同时决定策略优先级与噪声带内的把关族归属。评分接近（分差<0.02）时设置页就地提示，调序即切换把关族。
- **已收录模型全覆盖（H1＋H7）**：只要清单含 ≥2 个不同的**已收录**模型（锚定/估计混合亦然），每个至少占一族——任何排序都不会让某个已收录模型 0 行（全排列矩阵测试背书）；锚定＋估计混合下 F 的覆盖让位可跨 A-6 池（S 永远锚定严格）；未收录模型不承担覆盖（A-1 最后备选，行内徽章可见）。
- **导入导出（L2）**：右上「导出调研任务」＝**完整模型目录逐条**（含同模型多供应商的每条接入路由）＋单一英文调研提示词的 JSON 包（输出契约硬化：恰好 N 行/自包含/禁"同上"/禁引用标记/自检；重复回传导入时自动合并）（提示词诱导分布位置判断：50≈主流中位/70≈前四分之一/90≈前 10%）；「导入评估」粘贴回传 JSON（**「评分来源」**＝标题行第 4 钮，有评估或面板开启时出现：点开查看评估列表（行栅格，逐行可删），底部「一键清除评估·恢复默认评分」一键清空→评分回落内置 KB→Team 自动重派回导入前分配；导入成功自动展开、与导入面板互斥；保存生效，不保存离开即撤销）——重复行自动合并（后者胜，反馈明示）、全空维度/越界分行拒绝并逐条反馈；每行报告命中状态（当前候选/知识库/未命中；**路由限定行未命中任何接入路由时提示 provider 拼写**）；重导入保留手编路由限定行、仅替换通用行；导入行在「评分来源」面板逐条可删、一键清空回退内置快照。
- **语义档位物化**（0014 d1/0015）：最高/中/最低按所选模型实际档位表解析（梯子 off<minimal<low<medium<high<xhigh<max；off/none 不自动选；偶数上中位）——各家词表差异天然适配。
- **动态自适应**：候选清单增/删/改/重排即时**全表重评**；导入评估**应用即预览重派**（草稿层即时重算），**保存提交后运行时全表重评**（默认映射＋spread 策略下；自定义行为静态存储；运行中的子智能体在下一步边界换路）；模型档位变化（adapter 更新）200ms 防抖后重派生（档位自愈）。
- **copy-on-write**：编辑/添加/删除任一行 → 全表物化为自定义普通行＋`nameMapDefaults` 自动翻转 false。**恢复默认**＝标题行右侧**常驻单按钮**（两态都在；纯默认态灰显禁用＋悬停说明；点击只改草稿——保存前离开页面即撤销）。
- 保存语义不变：全页单按钮统一保存；派生预览随草稿实时变化、保存后生效。**五区"待保存"徽标**（候选清单/Team/兜底/高级/运行限制）即改即现——判定与保存操作流同口径，徽标亮必有对应保存项。`nameMapDefaults` 开启且存在存量行时显示非阻塞提示（不阻止保存）。
- 行内模型下拉只显示候选各一条（无重复项；悬空行显示占位）；删除操作悬停**序号**出现（弹层向右展开不越界）；候选清单行为单行渲染（完整 id 在悬停 title）。
