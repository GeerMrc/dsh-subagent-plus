# 设置页使用手册 / Settings page manual（v0.0.3，插件 dsh-subagent-plus）

设置 → **子Agent增强**。所有保存写入与手改 `cordis.patch.yml` 相同的 profile patch 层，且**热生效**（对新决策立即生效，无需重启；进行中的子 Agent 保持原路由，健康表/轮询游标/粘住决策全部保留）。

## 页面结构（v0.0.3：运行限制与候选清单同卡，候选清单=官方模型选择完整替代）

| 区块 | 控件 | 说明 |
|---|---|---|
| 页头 | 标题 + ⓘ 悬停说明 + **右侧完全接管开关** | 开关是 **bundle 级**插件开关（非配置项）：点击弹出**确认条**（关闭将完全禁用本插件并恢复官方「子智能体」设置页、本页随之卸载、重新启用走插件页）；确认后经插件管理器禁用——生产宿主 hmr 即时生效，启动型宿主显示"需重启生效"提示；失败显示重试提示。开关状态与插件页主开关联动同态；组合未提供插件管理服务时降级为提示文案 |
| **合并设置卡**（单一边框） | 顶部子区：**运行限制**（标题+ⓘ+已保存徽标 + 深度/并行两个数字输入）；留白分割后：**候选模型清单**（卡头行 + 清单行 + 添加行 + 策略行） | 运行限制同键写入官方 `subagent` 命名空间（强制仍由官方运行时执行，立即生效；非法输入**阻塞整次保存**；接管声明在 ⓘ 悬停中——官方页已隐藏、同一事实源、禁用即恢复）。候选清单即官方「模型选择」的完整替代（ADR 0003）：策略/逐模型推理强度/兜底/健康冷却；官方 allowlist 无编辑面，仅 host 半边只读桥接（钉定留空 autoRoute 采纳、空清单回落池）。pinned 策略下卡头为「钉定路由」下拉+推理强度；非 pinned 为清单行（序号+模型名+悬停操作条+推理强度下拉，≤5 条）+ 添加行 + 策略行 |
| 本插件命名空间失活分支 | 合并卡内状态行 | 本插件自身 ns 不可用/不可识别时仅策略半区转状态行，**运行限制子区照常编辑保存**（T7：接管期间不死锁）；官方 ns 失活仅运行限制子区转不可用行 |
| 兜底模型行（卡外） | 短标签下拉 + 推理强度下拉，悬停完整路由 | 候选全部不可用或清单为空时的最后路由；清单空+兜底=「单固定模型」入口 |
| **高级**折叠区 | 行式开关/输入 | **仅停用路由指派（保留接管）**（即原页头软开关，v0.0.2 的 `enabled:false` 语义不变）/ respectExplicit / showNotice / pinForkChildren / failOpen / autoRoute / cooldownMs |
| 页脚 | **全页唯一保存按钮** + 状态反馈 | 一次点击按固定顺序提交两个命名空间（运行限制 → 本插件配置），各自修订栅栏；失败在页脚点名分区 |

**统一保存门控**（v0.0.3）：按钮在"任一命名空间有修改且无阻塞项"时可用。任一**已服务**命名空间输入非法（运行限制解析失败 / 插件结构性或跨字段非法）阻塞**整次**保存（官方单表单语义）；**失活**的命名空间仅显示不可用行并被本次保存**排除**；首个冲突或传输失败**中止后续**命名空间并点名分区，已提交的分区保持已保存。

## 行为要点

- **保存即热生效**：改策略/清单只影响下一个决策点——已粘住路由的运行中子 Agent 不动，直到其路由进入冷却。
- **官方设置页接管**（v0.3.0 起）：插件启用期间官方「子智能体」设置页被隐藏（bundle patch disable，编辑面而已）；运行限制经本页同键读写官方命名空间，单一事实源。禁用/卸载插件后官方页面回归（生产宿主 hmr；源码启动宿主需重启），配置值保留；已存在子 Agent 从下一次请求起回官方解析。用户层 patch 写 `{id: ui-settings-subagent, disabled: false}` 可随时强制恢复官方页面（逃生门）。
- **完全接管开关 ≠ 软开关**（v0.0.3 起）：页头开关=bundle 级（关=官方页回归、本页卸载）；高级里的「仅停用路由指派」=软关（钩子惰性、路由回官方解析，**官方页保持隐藏**、本页保留）。
- **候选清单替代官方模型选择**（v0.0.3，ADR 0003）：官方授权清单无编辑面；已知边界——`respectExplicit=true` 且需调整官方白名单时，临时关闭本插件（官方页回归）编辑或手改 profile patch 的 `subagent-model-selection-settings` 行。
- **兜底触发条件**：候选全部冷却/未注册或清单为空。故障切换时**优先下一个健康候选**，兜底垫底；兜底自身故障同样进冷却，全部不可用时保持原路由（failOpen 语义）。
- **设置页与手改 yml 等价同层**：任何时刻都可回到 yml 手改或删除条目。
- **远程 web 会话限制**：非本机（非 loopback）访问时设置命名空间整区不可用——读写都不可用（官方 configForms 的 memory 持久化语义，describe mirror 不加载），配置区转不可用行、完全接管开关仍可用；桌面端与本机访问=持久落盘。
- **修订冲突**：配置在其他位置（如另一窗口）被改过时，保存会提示"已被修改，已重新加载"（分区点名）——重试即可。

## 验证方式

- 子 Agent 转录首行提示：`[model pinned/assigned/fallback: …]`；子窗口琥珀色徽章显示实际路由。
- Host 日志：`assigned (round-robin) child agent onto …`、`route "sz/…" failed (RATE_LIMIT); cooling down …`、`… continues with "hh/…"`。
- 端到端回归流程见 `docs/e2e-manual.md`（Flow A/B/C：改策略/配兜底+死路由降级/软关对照；**Flow E：接管面**——官方页隐藏/统一保存写入官方命名空间/完全接管开关/重启回归）。

## 推理强度下拉（v0.2.0）

- 选项来自**所选模型自身**的档位配置（目录 reasoning）：如 qwen 系 `Off/Low/Medium/Xhigh`、zai 系 `Low/High/Max`、无档位模型（如部分 Kimi）不显示下拉（钉定/兜底处显示禁用态）。
- 首项恒为「**默认**」（短标签，收窄占位）——不写该键，由 DSH 物化模型默认档位；**悬停选框**显示详情「跟随模型默认档位（当前：<档名>）」。
- 已存但当前模型不支持的档位 id 会**原样可见**（不会被静默改写），保存后由运行时校验兜底。
- 清空路由 → 档位清空；切换路由 → 已选档位在新模型仍支持时保留，否则回落「跟随默认」。
