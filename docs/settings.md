# 设置页使用手册 / Settings page manual（v0.0.4，插件 dsh-subagent-plus）

设置 → **子Agent增强**。所有保存写入与手改 `cordis.patch.yml` 相同的 profile patch 层，且**热生效**（对新决策立即生效，无需重启；进行中的子 Agent 保持原路由，健康表/轮询游标/粘住决策全部保留）。

## 页面结构（v0.0.4：运行限制与候选清单同卡，候选清单=官方模型选择完整替代）

| 区块 | 控件 | 说明 |
|---|---|---|
| 页头 | 标题 + 描述行 | 描述说明接管事实与唯一关闭入口（「插件」页停用本插件）。页内无任何开关（ADR 0005 纯二进制） |
| **合并设置卡**（单一边框） | 卡内自上而下：**运行限制**子区（标题+ⓘ+已保存徽标 + 深度/并行两个数字输入，64px 居中定宽）→ 留白 → **候选模型清单**（卡头行 + 清单行 + 添加行 + 策略行）→ **兜底模型行**（短标签下拉 + 推理强度下拉，悬停完整路由；候选全部不可用或清单为空时的最后路由，清单空+兜底=「单固定模型」入口） | 运行限制同键写入官方 `subagent` 命名空间（强制仍由官方运行时执行，立即生效；非法输入**阻塞整次保存**；接管声明在 ⓘ 悬停中——官方页已接管、同一事实源、插件页停用即恢复）。候选清单即官方「模型选择」的完整替代（ADR 0003）：策略/逐模型推理强度/兜底/健康冷却；官方授权清单无编辑面、运行时零引用（ADR 0005）——候选清单是唯一路由来源；未配置路由（钉定空+清单空+无兜底）时页面明示"不指派，子智能体继承主会话模型"。pinned 策略下卡头为「钉定路由」下拉+推理强度；非 pinned 为清单行（序号+模型名+悬停操作条+推理强度下拉，≤5 条）+ 添加行 + 策略行 |
| 本插件命名空间失活分支 | 合并卡内状态行 | 本插件自身 ns 不可用/不可识别时仅策略半区转状态行，**运行限制子区照常编辑保存**（T7：接管期间不死锁）；官方 ns 失活仅运行限制子区转不可用行 |
| **高级**折叠区 | 行式开关/输入 | respectExplicit（pinned 下置灰，仅轮询/随机/优先级生效——显式指派**也优先于角色关键词映射**，ADR 0013）/ showNotice / pinForkChildren / failOpen / cooldownMs（88px 居中；上限 86400000；钉定且未配兜底时冷却完全不参与并显示"当前配置下不生效"提示行；0=关闭在 ⓘ 内） |
| 页脚 | **全页唯一保存按钮** + 状态反馈 | 一次点击按固定顺序提交两个命名空间（运行限制 → 本插件配置），各自修订栅栏；失败在页脚点名分区 |

**统一保存门控**（v0.0.3）：按钮在"任一命名空间有修改且无阻塞项"时可用。任一**已服务**命名空间输入非法（运行限制解析失败 / 插件结构性或跨字段非法）阻塞**整次**保存（官方单表单语义）；**失活**的命名空间仅显示不可用行并被本次保存**排除**；首个冲突或传输失败**中止后续**命名空间并点名分区，已提交的分区保持已保存。

## 行为要点

- **保存即热生效**：改策略/清单只影响下一个决策点——已粘住路由的运行中子 Agent 不动，直到其路由进入冷却。
- **官方设置页接管**（v0.0.3 起）：插件启用期间官方「子智能体」设置页被隐藏（bundle patch disable，编辑面而已）；运行限制经本页同键读写官方命名空间，单一事实源。禁用/卸载插件后官方页面回归（生产宿主 hmr；源码启动宿主需重启），配置值保留；已存在子 Agent 从下一次请求起回官方解析。用户层 patch 写 `{id: ui-settings-subagent, disabled: false}` 可随时强制恢复官方页面（逃生门）。
- **候选清单=唯一路由来源**（ADR 0005）：官方授权清单无编辑面且运行时零引用；未配置路由=不指派（继承主会话模型）。需调整官方清单（如 `respectExplicit=true` 的白名单）时，到「插件」页停用本插件后官方页回归编辑，或手改 profile patch 的 `subagent-model-selection-settings` 行。
- **兜底触发条件**：候选全部冷却/未注册或清单为空；钉定路由故障（冷却）或未注册被跳过时同样由兜底接手。故障切换时**优先下一个健康候选**，兜底垫底；兜底自身故障同样进冷却，全部不可用时：已粘住路由的子 Agent 保持原路由继续尝试，新子 Agent 不指派（继承主会话模型）。
- **设置页与手改 yml 等价同层**：任何时刻都可回到 yml 手改或删除条目。
- **远程 web 会话限制**：非本机（非 loopback）访问时设置命名空间整区不可用——读写都不可用（官方 configForms 的 memory 持久化语义，describe mirror 不加载），配置区转不可用行；页内开关已随 ADR 0005 删除，远程会话请到本机「插件」页停用本插件（或改 profile）；桌面端与本机访问=持久落盘。
- **修订冲突**：配置在其他位置（如另一窗口）被改过时，保存会提示"已被修改，已重新加载"（分区点名）——重试即可。

## 验证方式

- 子 Agent 转录首行提示（**中英双语单行**）：`[模型钉定 model pinned: 本子智能体所有请求运行 sz/…｜every request runs sz/… — dsh-subagent-plus]`、`[模型指派 model assigned: …（策略：轮询｜strategy: round-robin）— dsh-subagent-plus]`（兜底/切换/failOpen 跳过同格式）；子窗口琥珀色徽章显示实际路由。
- Host 日志：`assigned (round-robin) child agent onto …`、`route "sz/…" failed (RATE_LIMIT); cooling down …`、`… continues with "hh/…"`。
- 端到端回归流程见 `docs/e2e-manual.md`（Flow A/B/C：改策略/配兜底+死路由降级/空配置不指派对照；**Flow E：接管面**——官方页隐藏/统一保存写入官方命名空间/页头无开关断言/重启回归）。

## 推理强度下拉

- 选项来自**所选模型自身**的档位配置（目录 reasoning）：如 qwen 系 `Off/Low/Medium/Xhigh`、zai 系 `Low/High/Max`、无档位模型（如部分 Kimi）不显示下拉（钉定/兜底处显示禁用态）。
- 首项恒为「**默认**」（短标签，收窄占位）——不写该键，由 DSH 物化模型默认档位；**悬停选框**显示详情「跟随模型默认档位（当前：<档名>）」。
- 已存但当前模型不支持的档位 id 会**原样可见**（不会被静默改写），保存后由运行时校验兜底。
- 清空路由 → 档位清空；切换路由 → 已选档位在新模型仍支持时保留，否则回落「跟随默认」。


## Team（角色关键词 → 路由）（v0.0.4，ADR 0006＋0007＋0008＋0010＋0012＋0013）

- 位置：合并卡内、策略选择行与兜底行之间；两种策略下均常显。
- **匹配语义**：队友名**包含**行关键词即命中（子串匹配，最长关键词优先）。关键词越短命中越广（最短 2 字符，最长 64，lower-kebab-case，不可为 `lead`）。
- **路由选定时机**：子智能体创建时经官方 `agent.model.select()` API 选定（在 step preparation 之前，0.2.2+ 宿主的正规通道）。冷却中的路由在**下一步边界**自动换到下一健康候选或兜底。
- **路由目标只能取自候选清单**（≤5 条；多行可共用）。钉定策略下映射区只读（含档位下拉）。
- **maxTokens**：继承预算跟随新路由持续生效（ADR 0010 裁定）。
- 校验（structural）：重名／半填／非法关键词（<2 字符）／悬空引用／超 32 行。
- fork 队友默认不被改写；空表＝休眠。
- `respectExplicit=true` 时，主智能体委派**显式指定**的模型（创建路由 ≠ 父会话当前路由）优先于关键词映射与策略链；恰等于父路由的指派无法识别（继承，ADR 0013 d4）。

### 起步配置（ADR 0013 d2）

- **单按钮**「填入通用起步配置」（替换旧版四模板下拉）：一键向草稿填入 12 行跨领域映射——review/audit/verif/plan→首选路由＋最高档；research/dev/build/execute/write/design→中位路由＋默认档；test/qa→末位路由＋最低档。**一张表服务所有会话场景**（开发/游戏/研究各取所需），未命中角色走策略链。
- **语义档位物化**（d1）：最高/最低档按所选模型**实际档位表**解析（公认梯子 off<low<medium<high<xhigh<max 就近取，off/none 不自动选；全不在梯子才按目录顺序取首末）——qwen 系（Off/Low/Medium/Xhigh）上"最高"=Xhigh，不再是"默认"。无法物化的行在应用摘要中**计数提示**，不静默降级。
- 槽位随候选数自适应：仅 1 条可用路由时全部同路由、按档位区分；≥2 条按 首选/中位/末位。
- 非空表先确认（替换/合并/取消，内联三选）；合并放不下时合并按钮禁用并显示所需/剩余行数；确认期间条件变化（清单清空/策略切钉定/容量不足）则**拒绝且不动草稿**。
- 按钮禁用条件：钉定策略／无可用候选／唯一候选路由无（非全 off 的）推理档位——禁用态悬停显示原因。
- 应用只改草稿（未保存提醒在应用摘要中）；应用后每行与手动行完全同构，可编辑/删除。
